# Field Expedition Ledger

Field Expedition Ledger is a local Go service for keeping geological field work connected from expedition planning through observations and specimen custody.

## Users and modules

- Field leads manage expedition lifecycle.
- Field observers submit site observations.
- Collection custodians register specimens.
- `internal/model` defines domain records and validation.
- `internal/store` provides an in-memory repository.
- `internal/service` coordinates state transitions and derived summaries.
- `internal/httpapi` exposes JSON APIs and the browser page.

## Run

```text
go run ./cmd/ledger
```

The service listens on `http://127.0.0.1:8090`. The browser page is available at `/`.

## Build and test

```text
go build ./...
go test ./...
```

## Configuration

- `LEDGER_ADDR` changes the listen address. The default is `127.0.0.1:8090`.
- `LEDGER_SEED` can be set to `false` to disable the small demo expedition.

## API

The JSON API supports expedition creation, activation, observation recording, specimen registration, closing, and summary review. All dates use RFC3339 and all identifiers are generated by the service.
